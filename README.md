# Delibera Demo

[**Abrir a demonstração navegável**](https://diegoalvesdevcuiabano.github.io/Delibera-Demo/landing.html)

Protótipo estático das telas do [Delibera](https://github.com/DiegoAlvesDevCuiabano/Delibera), sistema de gestão de solicitações acadêmicas. Ele permite conhecer a proposta e caminhar pelos fluxos de aluno e coordenação.

> **Estado:** demonstração visual. Os formulários, login, protocolos, decisões e preços mostrados nas telas **não operam um serviço real**. O comportamento atual do backend e as condições para um piloto estão descritos no [status técnico do Delibera](https://github.com/DiegoAlvesDevCuiabano/Delibera/blob/main/docs/status.md). As telas podem divergir da implementação.

## Por onde começar

- [Apresentação](landing.html) e [tour guiado](index.html).
- [Nova solicitação](nova-solicitacao.html), [confirmação](confirmacao-solicitacao.html) e [consulta](consultar-protocolo.html).
- [Painel da coordenação](dashboard-coordenacao.html) e [análise](analisar-solicitacao.html).

O site é composto por HTML, CSS e JavaScript estáticos. Para ver localmente, clone o repositório e abra `landing.html` no navegador. Nenhum banco, servidor Java ou conta de usuário é necessário para navegar pelo protótipo.

## Sobre o produto

O backend está em homologação técnica e ainda não está pronto para uso com dados reais. Se você avalia a solução para uma instituição, use esta demo para discutir os fluxos e consulte o [repositório do produto](https://github.com/DiegoAlvesDevCuiabano/Delibera) para o estado da implementação.
